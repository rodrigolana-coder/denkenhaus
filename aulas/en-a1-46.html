Section 2 of 5
Grammar

1. WOULD LIKE

We use would like when we want something in a polite way.

I’d like + noun

I’d like the chicken.

I’d like some rice.

I’d like a coffee.

I’d like the chocolate cake.

I’d = I would

2. WOULD YOU LIKE...?

Use Would you like...? to offer something politely.

Would you like some water?

Would you like a dessert?

Would you like some vegetables?

Would you like something to drink?

Answers

Yes, please. / No, thank you.

3. CAN I HAVE...?

Another common way to order something: Can I have + food/drink + please?

Can I have the fish, please?

Can I have some water, please?

Can I have a coffee, please?

Can I have the bill, please?

4. LIKE × WOULD LIKE

LIKE = general preference ❤️

I like chocolate. = Eu gosto de chocolate.

I like eating fish. = Eu gosto de comer peixe.

WOULD LIKE = what you want now 🍽️

I’d like some chocolate. = Eu gostaria de chocolate.

I’d like the fish, please. = Eu gostaria do peixe, por favor.
