Seção 2 de 5
Gramática — Parler de ses compétences

1. Savoir + infinitif

Usa-se savoir + infinitivo para indicar que uma pessoa possui uma competência prática.

Je sais utiliser ce logiciel.

Elle sait organiser des événements.

Nous savons travailler en équipe.

Ils savent communiquer avec les clients.

⚠️ Aqui, savoir não significa apenas "conhecer uma informação" — também significa "saber fazer alguma coisa".

2. Être capable de + infinitif

Essa estrutura indica que uma pessoa possui a capacidade necessária para realizar uma ação.

Je suis capable de travailler sous pression.

Elle est capable de gérer plusieurs tâches.

Nous sommes capables de résoudre ce problème.

Comparação: Je sais utiliser ce programme. (sei usar) × Je suis capable d’utiliser ce programme. (sou capaz de usar) — as duas frases são próximas, mas être capable de enfatiza mais a capacidade.

3. Maîtriser + substantivo

Maîtriser significa possuir um conhecimento ou controle muito bom de algo.

Je maîtrise l’anglais.

Elle maîtrise plusieurs logiciels.

Nous maîtrisons les outils numériques.

⚠️ Diz-se: maîtriser une langue, maîtriser un logiciel, maîtriser une technique.

4. Avoir de l’expérience dans / en

Essa estrutura permite falar de uma experiência já adquirida.

J’ai de l’expérience dans la communication.

Elle a de l’expérience en administration.

Il a trois ans d’expérience dans ce domaine.

Estruturas úteis: avoir de l’expérience dans un domaine / en informatique / avec les clients / deux ans d’expérience.

5. Être spécialisé(e) dans / en

Essa expressão apresenta a principal área profissional de uma pessoa ou empresa.

Je suis spécialisé dans le marketing.

Elle est spécialisée en droit du travail.

Cette entreprise est spécialisée dans les nouvelles technologies.

6. Être passionné(e) par

Essa estrutura permite falar de um interesse muito forte.

Je suis passionné par les langues.

Elle est passionnée par la communication.

⚠️ Concordância: un homme passionné; une femme passionnée; des hommes passionnés; des femmes passionnées.

7. Apresentar seu perfil profissional

Para apresentar seu perfil, pode-se organizar as informações nesta ordem:

1. Formação — J’ai un diplôme en communication.

2. Experiência — J’ai travaillé pendant trois ans dans une entreprise internationale.

3. Competências — Je sais organiser des événements et je maîtrise les réseaux sociaux.

4. Qualidades — Je suis sérieux, autonome et organisé.

5. Motivação — Je suis passionné par ce domaine et je voudrais développer mes compétences.

8. Mini résumé

savoir utiliser… / être capable de travailler… / maîtriser… / avoir de l’expérience dans… / être spécialisé en… / être passionné par…
